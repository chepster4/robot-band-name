## The line

> **The Uninstalled — hit single 'You Deleted Me (But I Backed Up)'**

A band of robots that got uninstalled — and their hit is a breakup
ballad with a backup twist. The name reads like a real indie band;
the song fits the name (uninstalled / deleted) and adds the second
laugh instead of repeating the first one. No stale robot pun, no
explaining the joke.

## How to run

Requires Node 22 or later. No dependencies.

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (UTF-8, one line,
63 characters, no trailing newline).
